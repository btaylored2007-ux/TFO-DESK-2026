# eToro public design review (2026-11-07, UTC+8)
Sources: https://apps.apple.com/us/app/etoro-investing-made-social/id674984916 ; https://play.google.com/store/apps/details?id=com.etoro.openbook (not fetched)
Seen: 6 official App Store marketing screenshots (etoro/s1-s6.png, contact.png): low fees, Academy "New to investing?", $100K virtual/demo account, trading tools (charts/sentiment/price alerts/stop loss), asset discovery tiles, account-value home. NOT seen: real welcome/login/sign-in screen, bottom tab bar (cropped out). No sign-in performed.
Findings:
1. Dark near-black canvas + one bright accent; numbers are the hero (large balance, small green delta). Adapt: deep emerald/cream, burgundy for losses/alerts.
2. One headline + one primary pill CTA per screen ("Start Course"). Adapt for THF welcome/practice check.
3. Card grid with generous ~16px insets and rounded corners -> fixes cramped practice-check edge text.
4. Demo/virtual account framed prominently as risk-free practice -> label THF paper mode clearly.
5. Disclaimer in small muted footer, not inline clutter -> declutter chat list.
6. Single consistent palette across header and body -> replace navy header.
